# 🐍 Python - Projetos e Scripts

Repositório com projetos e scripts em Python para estudo e prática de programação. Aqui você vai encontrar exercícios, mini projetos, automações e jogos desenvolvidos em Python.

## Objetivo

O objetivo deste repositório é:
- praticar e melhorar habilidades em programação Python;
- desenvolver o pensamento lógico;
- aplicar conceitos fundamentais em projetos reais;
- organizar scripts e projetos de forma clara;
- documentar o aprendizado e evolução;
- criar um portfólio com projetos funcionais.

## Tecnologias utilizadas

- **Python 3** - linguagem de programação
- **Visual Studio Code** - editor de código
- **Terminal/CMD** - execução de scripts
- **GitHub** - versionamento de código

## Conceitos já aprendidos

- ✅ Condicionais (`if`, `elif`, `else`)
- ✅ Importação de bibliotecas
- ✅ Funções e definição de funções
- ✅ Estruturas de repetição (`for`, `while`)
- ✅ Variáveis e tipos de dados
- ✅ Listas, tuplas e dicionários
- ✅ Strings e manipulação de texto
- ✅ Entrada e saída de dados (`input`, `print`)
- ✅ `f-strings` para formatação de texto
